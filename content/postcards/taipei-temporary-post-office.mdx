Not every postcard in this archive was bought — some were made. This one is handmade, carrying a set of Taiwan's cute-animal definitive stamps, and it picked up two postmarks on the way out: one from a **temporary post office** set up for an event, and a second from **Taipei Main Post Office** itself. Two cancellation marks on one card is a small, accidental record of exactly how it moved through the system before it ever left the country.
